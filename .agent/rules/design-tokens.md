# Design Tokens — Pelindo Brand Palette

> Diambil dari referensi pelindo.co.id dan tps.co.id (Terminal Petikemas Surabaya).
> Semua styling frontend WAJIB pakai token ini, jangan pilih warna baru sembarang.

## Warna Utama

| Token | Hex (kira-kira) | Kegunaan |
|---|---|---|
| `primary` | `#0072BC` | Warna brand utama — tombol utama, judul, logo accent |
| `primary-light` | `#2D9CDB` | Hover state, ikon, link |
| `navy` | `#0B3D6B` | Background section gelap, hero overlay |
| `navy-dark` | `#1A2E4A` | Footer, elemen paling gelap |
| `neutral-bg` | `#F5F7FA` | Background section terang (pembeda dari putih polos) |
| `white` | `#FFFFFF` | Background utama |
| `text-dark` | `#1A1A1A` | Teks body di atas background terang |
| `text-muted` | `#6B7280` | Teks sekunder/caption |

## Tipografi
- Font: sans-serif tegas (mirip Helvetica/Inter), bold untuk heading
- Heading: huruf besar (uppercase) untuk section title, mengikuti gaya web Pelindo
- Body text: regular weight, ukuran nyaman dibaca (16px base)

## Kesan Visual
- Korporat, maritim, clean, banyak whitespace
- Hindari warna mencolok di luar palette (misal merah/kuning terang) kecuali
  untuk status indikator (error/warning) yang memang butuh warna semantik terpisah

## Status/Semantic Colors (di luar brand, untuk UI feedback)
| Token | Hex | Kegunaan |
|---|---|---|
| `success` | `#22C55E` | Absen berhasil / wajah terverifikasi |
| `error` | `#EF4444` | Absen gagal / wajah tidak cocok |
| `warning` | `#F59E0B` | Perlu perhatian (misal similarity borderline) |

## Catatan
Palette ini masih estimasi visual dari screenshot, BUKAN hex resmi dari brand
guideline Pelindo. Kalau nanti mentor/pihak Pelindo memberikan brand guideline
resmi (misal file PDF/AI dari tim desain), file ini WAJIB diperbarui mengikuti
sumber resmi tersebut.
